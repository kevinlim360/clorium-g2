저장 경로·상품 폴더명은 미감개선 때문에 바뀌지 않는다. 과거 구현 기록의 기본 구조는 `DownloadFolder/yyyy년MM월/dd일/CloriumID+상품번호`, 충돌 시 `___1` 등의 기존 처리이다. 고객의 실제 설정과 코드가 최종 기준이며 임의로 새 경로를 고정하지 않는다. 미감개선은 원본을 한 벌만 저장한다. AutoSizing은 PR 파일도 기존과 동일하게 인식해야 하며 치수사진·결과·CSV에 PR을 붙이지 않는다.

## 미감개선 모드

1. 설정 Custom에 기능 사용 선택을 둔다. 선택되어 있으면 프로그램 실행·재시작 및 PC 재부팅 후 앱 시작 때 런타임 모드는 ON이다.
2. 화면의 하자 옆에 미감개선 체크박스를 표시한다. 클릭 시 상태와 버튼 색을 동기화하고 메인·미리보기의 실제 이미지 테두리만 오렌지색으로 표시한다.
3. 화면에서 OFF로 전환하면 상품을 여러 번 바꾸어도 OFF를 유지한다. 다음 토글까지 유지하고, 다음 실행은 Custom 선택 조건에 따라 ON으로 시작한다.
4. 고객 원 요구에 Monsterdeck 토글이 있지만 사용자가 직접 추후 구현하겠다고 제외했다. 현 이관 범위에서 완성되었다고 표현하거나 임의 추가하지 않는다.

## 수퍼포커스 현재 요구사항

이 절은 현지 프로젝트의 후속 개발 기록을 반영한다. EOS R, RF24–105 및 RF24–240을 대상으로 기존 고장 난 수퍼포커스·동영상을 개발 소스에서 비활성화하고 새 순차 촬영·다운로드·합성 경로를 추가했다. baseline은 보존한다.

- 포커스 박스와 A/B 지정, 작은 SDK 명령 기준 가까이/멀리 1·5·20 수동 이동을 제공한다. A/B는 절대 거리 또는 광학 DOF가 아닌 상대 초점 단계이다.
- 고스트 바로 위 왼쪽 메뉴에서 작은 이동형 팝업을 연다. 조작부는 초점, 품질·컷수·포커스박스, 촬영의 세 줄로 압축하고 상세 설명은 툴팁/고급설정에 둔다.
- 최종 고 품질은 3작은단계마다 촬영하고 마지막 끝점도 포함한다. 중/저는 고 컷수의 약 2/3·1/3 반올림, 최소 2컷이다. A0/B72 예는 고25·중17·저8이다. 이전 73/49/24 및 고=1단위 규칙은 폐기된 이력이다.
- A/B 지정 후 고 선택과 컷수 자동표시. 직접입력은 2..고 최대, 전체 200컷 상한. 품질 전환·숫자 입력·Refresh가 서로 덮어쓰지 않아야 한다.
- A→B 또는 B→A 순서 지정 및 촬영 지원. 현재 초점에 가까운 끝점부터 시작한다. 이미 끝점이면 불필요한 복귀와 첫 대기만 생략하고 이후 안정화·다운로드 대기는 보존한다.
- A 탐색 중 박스 표시를 즉시 이동할 수 있다. 반대 지점 요청은 클릭 당시 ROI를 복사해 예약하고 카메라 작업은 직렬 처리한다. 중지·오류·연결 끊김 때 예약을 취소한다.
- 최신 수동 화살표 전환: 자동탐색/반대지점 예약 취소 → 네이티브 AF 정지 → 현재 초점을 해당 A/B로 저장 → 수동 이동을 순서대로 수행한다. 탐색 정점 완료로 가장하지 않는다. 촬영·전송 중 수동 이동 잠금은 유지한다.
- 원본을 보존하고 다운로드 완료 전 다음 초점 이동을 하지 않는다. 중지 후 늦게 도착한 원본도 보존한다. 실패·중지 상황을 정상 완성 합성으로 보고하지 않는다.
- 렌즈 AF 및 카메라 Continuous AF OFF 조건을 안내한다. 링·줌·렌즈·장면 변경 시 재지정한다. CPU 8-bit RGB 합성으로 RAW/16-bit/RTX 가속은 지원하지 않는다.
- 새 동영상 서비스는 미구현이다. RF24–240 실기, 다양한 상품의 광학 품질, 최신 수동전환 코드의 실카메라 검증은 남아 있다.

## 라이선스와 배포

기존 4.7.1.4 요구는 D드라이브의 여러 키 후보 중 실제 PC정보와 일치하는 유효 파일이 하나라도 있으면 인정하는 것이다. 임의 lock 파일을 허용하는 우회가 아니다. 후속 G2는 별도 회사용 관리 앱, 서버, 고객 SDK를 개발했다.

- 고객/시리얼/버전/PC, 영구·데모·테스트, 온라인·오프라인, PC 반납·강제회수, 이력·CSV·전체 백업을 관리한다.
- 고객은 .NET Framework 4.8, 서버/회사 WPF 앱은 .NET 10이다. 기본 확인 하루 1회, 네트워크 유예 30일이며 기간제 만료가 우선한다.
- 관리 라이선스 필수 배포 빌드는 공개키·서버 주소를 내장하고 기존 lock/EXIF 검사로 내려가지 않는다. 일반 개발 빌드는 기존 정식 발급 경로를 유지한다.
- 촬영 진입/외부 셔터는 차단하되 이미 진행 중인 원본 다운로드·저장을 강제 중단하지 않는다.
- 현재 후보 주소는 `http://127.0.0.1:5088`이다. 외부 고객 배포용으로 사용할 수 없다. 운영 도메인·서버 정보가 필요하고 기존 키/DB 복원, HTTPS 설정, 필수모드 재빌드, 고객 PC 검증이 남아 있다.
- 사용자 배포 선호는 Windows에서 직접 실행하는 업데이트이며 PowerShell 수동 실행을 요구하지 않는 것이다. 현재 라이선스 후보의 설치 스크립트는 최종 사용자 업데이트 EXE 요구 충족으로 보지 않는다. 기존 설치·사진·설정 보존 및 롤백이 필수다.
- 회사 데이터/서명 개인키/관리자 토큰/기존 호환키는 Claude 첨부물·소스 ZIP·Git에 넣지 않는다. 같은 PC의 기존 파일을 필요 시 로컬 빌드 입력으로만 참조한다.

## 인수 검증 기준

1. F/B/D × 미감 ON/OFF × 다음 상품 × AF 실패/재시도 × 지연 다운로드를 실제 저장파일까지 검사한다. 하자·치수·턴테이블 PR 제외를 포함한다.
2. 시안 6조합, 최소 창 크기, 다양한 DPI·세로/가로/회전 이미지, 썸네일과 확대를 검증한다. 테두리가 실제 이미지와 일치해야 한다.
3. 실제 CameraPreset 저장·재실행·불러오기·장치 미지원 설정·중복명·촬영 중 조작을 확인한다.
