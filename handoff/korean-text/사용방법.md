# 한글 문구·용어 목록 사용 방법

클로리움 G2 화면과 메시지에 나오는 한글 문구를 모두 모은 목록입니다(2026-11-04 기준, 1,688곳 · 서로 다른 문구 1,344개).
`src/Clorium.G2/tools/KoreanText` 도구가 소스에서 뽑았고, 고친 문구를 같은 도구가 원래 자리에 다시 넣습니다.

## 파일 두 개

| 파일 | 한 줄의 의미 | 고칠 칸 |
|---|---|---|
| `한글문구_고유.csv` | 서로 다른 문구 하나 (예: "맞춤"이 4곳에 쓰여도 한 줄) | **새 문구** — 쓰인 곳 전체에 같이 바뀜. 용어 통일에 사용 |
| `한글문구_위치.csv` | 문구가 쓰인 자리 하나 (파일·줄·종류·용도) | **새 문구** — 그 자리만 바뀜. 고유 목록보다 우선 |

둘 다 엑셀에서 바로 열립니다. 바꿀 문구의 **새 문구** 칸만 채우고, 비워 둔 줄은 그대로 둡니다.
저장할 때는 「CSV UTF-8(쉼표로 분리)」 형식을 권장합니다. 일반 「CSV(쉼표로 분리)」로 저장해도 읽습니다.

## 열 설명 (위치 목록)

- **파일 / 줄**: `src/Clorium.G2/projects/` 아래 기준 위치
- **종류**: `C# 문자열`(코드의 메시지), `XAML Text/Content/ToolTip/Header/Title`(화면 글자), `XAML 검색어(Tag)`(설정 창 검색용 단어), `언어 파일`(Languages/ko.xml — 기존 다국어 화면 문구, 용도/키 칸에 이름)
- **용도/키**: `메시지 상자`, `오류`, `화면 문구`, `로그`(개발용 기록 — 고객에게 보이지 않음), `비교/키`(코드가 이 글자를 비교하는 곳 — **바꾸면 동작이 달라질 수 있으니** 바꿀 때 알려 주세요)
- **원본 줄**: 문구가 들어 있는 소스 한 줄(참고용)

## 지켜 주실 것

- `{0}`, `{1}`, `{name}`처럼 중괄호로 된 부분과 `\n`(줄바꿈), `%s`, `&#10;`는 **그대로 남겨** 주세요. 개수가 달라지면 그 줄은 반영하지 않고 결과에 이유를 적습니다.
- 줄을 바꾸고 싶으면 엔터 대신 `\n`을 그대로 쓰세요(C# 문자열).
- 큰따옴표(")와 &, < 같은 문자는 그대로 쓰시면 도구가 알맞게 바꿔 넣습니다.

## 반영 (Claude가 실행)

고친 CSV를 이 폴더에 다시 두고 요청하면 아래를 실행합니다. 먼저 미리보기로 확인한 뒤 실제로 반영하고, 빌드·검사합니다.

```
dotnet tools/KoreanText/bin/Release/net10.0/KoreanText.dll apply projects ../../handoff/korean-text --lang projects/CameraControl/Languages/ko.xml --dry-run
```

결과는 `반영결과.txt`에 「반영 파일:줄 '이전' → '새 문구'」와 「건너뜀 … 이유」로 남습니다.
목록을 만든 뒤 소스가 바뀌어도 파일과 문구로 자리를 다시 찾으므로, 이미 바뀐 곳만 건너뜁니다.
