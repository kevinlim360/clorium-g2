# 클로리움라이선스관리

이 폴더는 라이선스 관리 전용 Claude Code 프로젝트 작업 디렉터리이다. 소스와 Git 저장소는 `../..`에 있으며 같은 소스를 사용한다. 모든 빌드 명령은 저장소 루트에서 실행한다. 다른 G2/수퍼포커스 작업을 이 프로젝트의 첫 작업으로 선택하지 않는다.

우선 `../../handoff/licensing/START_HERE.txt`, `PRD.md`, `DEVELOPMENT_HANDOFF.md`, `CHECKS.md`를 읽는다. 라이선스 정책은 이 전용 PRD와 모듈 README가 과거 전체 G2 PRD보다 최신이다. 한국어로 작업하고 실제 소스/실행 결과를 확인한다.

정식은 같은 PC 최초 1회 인증 후 영구 오프라인, 직원 테스트/데모는 PC 고정과 KST 3개월 온라인 재인증이다. 기존 소스는 `../../modules/Clorium.Licensing`, 제품 통합은 `../../src/Clorium.G2`이다.

`.local`의 개인키·토큰·회사 DB·백업은 열어 출력/전송/커밋하지 않는다. 기존 서명키를 보존한다. 설치본·사진·설정·baseline·다른 실행 앱/카메라를 건드리지 않는다. 첫 단계는 DNS/서비스 상태 진단이며 실제 운영 배포 완료로 가정하지 않는다.
