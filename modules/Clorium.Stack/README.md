# Clorium Stack 0.1

ModeStack에서 확인한 라플라시안 피라미드·회색조 제곱 에너지·층별 컬러 계수 선택·복원 흐름을 참고하여 **새로 구현한 독립 초점 합성 엔진**입니다. ModeStack.exe의 이름 변경이나 바이너리 복제가 아닙니다. 원본과 모든 결과가 같다는 의미도 아닙니다.

## 실행

이 PC에서는 `Clorium Stack 실행.ps1`을 실행합니다. 사진 선택 → 같은 구도로 초점만 바꾼 사진 2장 이상 선택 → 초점 합성 시작. 저장 위치 기본값은 첫 입력 사진 폴더 아래 `Clorium_Stack`입니다. 기존 파일이 있으면 ` (1)`, ` (2)`를 붙입니다. 입력은 수정하지 않습니다.

Python 3.12 환경과 `requirements.txt`가 필요합니다. 현재 PC 실행기는 기존 배경제거 개발용 Python 환경을 사용합니다. 다른 PC용 EXE/설치 프로그램은 아직 아닙니다.

CLI: `python clorium_stack.py first.jpg second.jpg -o result.png`

- `--no-align`: 고정 촬영에서만 자동 정렬 생략
- `--levels 5`, `--window 55`: 피라미드 깊이, 에너지 평활 창
- `--memory-mb 6144`: 사전 메모리 추정 상한(MiB), 실제 OS 메모리 예약은 아님
- `--cancel-file PATH`: 해당 파일 생성 시 단계 경계에서 중지. 종료코드 130
- stdout: 진행/결과 JSON 한 줄씩. 결과 폴더에 JSON 파일은 만들지 않음
- 성공 0, 오류 1. Python 프로세스 실행은 shell 없이 인자 배열/안전한 인자 인코딩 사용

## 구현 경계

ModeStack 근거는 `research/modevid-feature-modules/superfocus/algorithm-map.md`에 함수 주소와 함께 보관합니다. 원본의 모든 모드와 설정은 복원되지 않았습니다.

새 구현의 선택: ORB 서술자/Hamming 매칭/RANSAC 유사 아핀 정렬, float32 피라미드, 동일 점수 시 기존 계수 유지, 중간 입력을 기준 프레임으로 선택, 기준 프레임의 가장 낮은 주파수 층 유지, 정렬 유효영역만 선택. 이는 ModeStack 전체 파라미터/BRIEF/FLANN 경로의 정확한 복제가 아닙니다.

색상 자동 보정은 하지 않으며 공통 ICC 프로필은 출력에도 보존합니다. 불필요한 EXIF는 저장하지 않습니다. 같은 입력 이미지 합성 시 픽셀 일치 검사를 수행합니다. 다른 초점 사진을 합성하면 선택·정렬·보간·복원 때문에 개별 입력 픽셀과 완전히 동일할 수는 없습니다.

8-bit RGB/그레이 JPEG·PNG·TIFF를 지원합니다. RAW, 16-bit, 투명 입력은 조용히 변환하지 않고 거부합니다. 출력은 원본 해상도의 RGB PNG(중간 압축 6). 현재 **CPU 구현**이며 RTX/CUDA 가속은 없습니다. 사진 수에 비례해 원본 전체를 메모리에 누적하지 않지만 30MP 원본 합성에는 수 GB의 작업 메모리가 필요합니다.

초점 선택 경계의 halo, 반사·투명 물체, 큰 브리딩과 반복무늬는 실사 검증이 필요합니다. 정렬이 검증 기준을 넘지 못하면 결과를 저장하지 않습니다. 중지는 이미지 읽기/정렬/OpenCV 연산/PNG 저장 중간을 강제로 끊지 않고 연산 종료 후 확인합니다.

## G2 및 카메라 상태

독립 실행과 G2 새 수퍼포커스 촬영 창 연결이 가능합니다. G2 개발본의 **파일 → 수퍼포커스 (G2)**에서 기존 라이브뷰·JPEG 단독 촬영 → 원본 다운로드 완료 → 초점 이동 → 합성 엔진을 순서대로 실행합니다. 기존 고장 난 수퍼포커스/동영상 경로의 차단은 유지하며 `baseline`은 원본 보존용입니다.

2026-10-28 EOS R + RF24-105mm F4 L IS USM(24mm)에서 2장/6장 및 8장 촬영·다운로드·합성 저장과 중지 후 부분 원본 보존을 확인했습니다. **본체 컨티뉴어스 AF를 끄고 렌즈는 AF로 유지**해야 하며, 해당 설정 해제 후 실제 초점 변화와 가까운/먼 디테일 합성을 확인했습니다. RF24-240mm는 사용자 요청으로 오늘 시험에서 제외했습니다. 상품별 halo/색/속도 및 ModeStack 원본과의 출력 동등성은 미검증입니다. 세부 후보·한계·근거는 `../../촬영기능_교체현황.md`, `../../evidence/superfocus-20261028.json`을 참조하세요. 새 동영상 서비스와 설치 패키지는 아직 없습니다.
