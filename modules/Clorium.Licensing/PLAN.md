# 클로리움 라이선스 관리 구현 기준

요청: Windows 영구 사용 제품의 시리얼·버전·고객사·PC를 관리하고 데모/테스트 만료와 복제를 제어한다. Cryptlex와 유사한 핵심 기능을 CameraControl에 내장하고 회사 관리 앱을 만들어 최소 관리로 운영한다. Cryptlex 전체 서비스 복제나 SDK 사용이 아닌 자체 구현이다.

## 사용자 흐름과 합격 기준

1. 회사 관리 앱에서 고객사/담당자와 제품, 허용 주요 버전, 설치 대수, 영구·데모·테스트, 만료일을 입력해 무작위 시리얼을 발급한다. 조회·검색·만료 연장·차단·차단 해제·PC 강제 회수·이력·내보내기를 제공한다.
2. 고객은 CameraControl 내 최초 인증 창에서 시리얼 한 번을 입력한다. PC 지문과 버전을 자동 등록하고 서명된 권한을 로컬에 보호 저장한다. 이후 자동 검증/갱신한다. 기존 승인된 촬영·저장·수퍼포커스 기능은 변경하지 않는다.
3. 영구 권리와 재확인 유예를 구분한다. 기본 자동 재확인 1일/네트워크 유예 30일은 운영 초기값으로 설정 가능하게 한다. 영구 오프라인은 회사가 명시 발급할 때만 허용한다. 데모/테스트는 실제 만료일을 네트워크 유예로 연장하지 않는다.
4. 같은 PC 재인증은 멱등적, 다른 PC는 좌석 제한. 정상 이전은 온라인 반납 뒤 새 인증. 고장 PC 강제 회수는 회사 앱에서 사유를 남긴다. 이미 오프라인인 옛 PC는 발급된 토큰의 확인 기한까지 실행 가능하다는 한계를 표시한다.
5. 오프라인 PC는 요청 파일 생성→회사 앱 가져오기→서명 응답 파일 발급→고객 가져오기. 응답은 지정 PC/제품/버전에만 유효하고 좌석을 소비한다. 사용 데이터는 삭제하지 않는다.
6. 서버는 관리자 인증, 서버 전용 개인 서명키, 크기 제한/요청 제한, 원자적 저장/백업/단일 작성자 보호를 갖는다. 고객 배포물에 관리자 비밀·개인키를 포함하지 않는다. 클라이언트는 서명·PC·제품·버전·기간·시계 역행을 검증한다. 시간/VM 스냅샷 공격과 완전 오프라인 즉시 회수 불가능성을 문서화한다.
7. 새 라이선스 설정이 있는 CameraControl은 새 모듈로만 검증하며 실패 시 기존 .lock 방식으로 우회하지 않는다. 새 모드에서는 EXIF 날짜 기반 CompareDate_Ex를 호출하지 않는다. 설정 없는 기존 개발/기존 납품본의 정식 발급 라이선스 경로는 유지한다. 신규 발급용 배포는 공개키/서버 주소를 고정한 빌드와 필수 새 모드로 만든다.
8. 실행 중 주기 검사와 촬영 진입 경계에서 만료를 확인한다. 만료/회수 시 새 촬영을 막고 이미 진행 중인 다운로드/저장은 마무리한다. 서버의 명시적 차단·회수·만료는 네트워크 오류와 구별해 캐시 유예로 허용하지 않는다. 데모에서 정식 전환은 재설치/고객 데이터 변경 없이 처리한다.
9. 서명키·관리자 설정·저장소 전체를 백업/복원하는 경로를 제공하고 복원 후 기존 고객 재인증을 검사한다. 고객 배포물에는 개인키·관리자 비밀이 없고 필수 새 모드·공개키가 고정돼 설정 파일 삭제로 레거시로 내려가지 않음을 검사한다. PC 지문은 보드/펌웨어 기반으로 RAM/디스크 교체에 영향받지 않게 하고 메인보드 교체는 이전 흐름을 사용한다.

## 구현과 전달

- 공통 서명/프로토콜, .NET Framework 4.8 고객 SDK/인증 창, .NET 10 인증 서버, Windows WPF 회사 관리 앱을 새 modules/Clorium.Licensing에 둔다. 외부 패키지 없는 기존 런타임/참조 어셈블리 경로를 우선 사용한다.
- 소규모 운영을 위한 단일 서버의 원자적 파일 저장소를 사용한다. 다중 서버/대규모 DB 운영과 결제·리셀러·플로팅 과금은 이번 사용자 흐름에 넣지 않는다.
- 회사 앱은 한국어, 밝은 중성색, 고객/라이선스/설치PC/이력을 한 화면에서 연결한다. 고객 창은 시리얼 입력/현재 상태/이전/오프라인 파일 처리에 집중한다.
- 보안·교차 시스템 의존성이 있어 별도 검토자가 이 계획을 검토한 후 구현한다. 최종 후보도 별도 읽기 전용 검토를 받는다.
- 검증: 영구/기간제 발급·정상/다른PC·좌석 경합·반납/이전·차단/복원·오프라인 발급·변조/다른서명키·버전초과·만료·시계역행·재시작 지속성·관리자 미인증 거부·CSV/백업을 실제 로컬 서버와 .NET Framework 고객 코드로 확인한다. WPF 화면을 렌더해 확인하고 CameraControl 빌드/기존 차단 검사를 수행한다.
- 사용자는 회사 서버 또는 클라우드 상시 운영을 선택했다. 이 작업 폴더에 실행 가능한 회사 앱/서버, 고객 DLL/통합 CameraControl 후보, 빌드·실행·배포 스크립트/안내와 검증 근거를 전달한다. 실행 중인 기존 개발본 및 설치본을 강제 종료/교체하지 않는다. 운영 도메인/TLS/외부망 설치는 운영 대상이 정해진 후 연결하며 로컬 검증을 운영 배포 완료로 표현하지 않는다.
