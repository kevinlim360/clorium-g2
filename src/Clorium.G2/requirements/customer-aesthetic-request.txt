제안요청서 · 무신사 유즈드
클로리움 촬영 소프트웨어 ‘미감 개선’ 모드 추가
발주처: 무신사 · 작성일: 2026. 10. 19.
Ⅰ. 개요
1. 목적
촬영한 이미지 중 일부를 별도 보정 공정으로 따로 가공하려고 합니다.
작업자가 촬영 전에 상품의 가공 타입을 판단하고, 그 타입에 맞는 모드로 촬영합니다.
무신사 유즈드 시스템은 파일명으로 가공 대상인지를 구분합니다.
2. 기대효과
작업자가 촬영 시점에 판단한 가공 타입을 별도 입력 없이 무신사 시스템에 전달
미감 개선 대상만 선별해서 가공
몬스터덱으로 모드를 전환할 수 있어 촬영 흐름이 끊기지 않음
3. 현황
구분 AS-IS TO-BE
촬영 소프트웨어 모드 개념 없음 ‘미감 개선’ 모드(ON/OFF) 추가
모드 제어 해당 없음 촬영 소프트웨어 화면과 몬스터덱 버튼 양쪽에서 ON/OFF 전환
촬영 가공 타입과 관계없이 촬영 작업자가 가공 타입을 확인하고 모드 ON/OFF 후 촬영
화면 모드 표시 없음 촬영 화면에서 현재 모드를 확인할 수 있음
저장 기존 파일명으로 저장 모드에 따라 정해진 파일명으로 저장
Ⅱ. 제안요청 사항
1. 기능 요구사항
모드 기능 (촬영 소프트웨어)
ID 항목 요구사항 구분
R2-1 모드 추가 클로리움 촬영 소프트웨어에 ‘미감 개선’ 모드(ON/OFF)를 추가합니다. 필수
R2-2 소프트웨어에서 전환 촬영 소프트웨어 화면에서 모드를 ON/OFF 할 수 있습니다. 필수
R2-3 모드 유지 상품이 바뀌어도 모드는 다음 전환 전까지 유지됩니다.
예: 모드 ON → 1번 상품(미감 개선 대상) → 2번 상품(미감 개선 대상) → 모드 OFF → 3~6번
상품(기존)
필수
R2-4 초기 상태 프로그램 실행, 재시작 시 모드 ON 상태로 시작합니다. 필수
R2-5 모드 표기 작업자가 현재 ON인지 OFF인지 촬영 중에 바로 알아볼 수 있게 표시합니다. 문구만으로는 놓
칠 수 있어 눈에 잘 띄는 방식을 원합니다(예: 촬영 화면 상단 고정 배지, 화면 테두리 색 변경).
구체적인 방식은 수행사에서 제안해 주세요.

5. 검수 기준
촬영 소프트웨어 화면과 몬스터덱 양쪽에서 모드가 전환되고, 두 곳의 상태가 일치하는지 확인
모드 ON/OFF 각각 촬영했을 때 위 파일명 규칙대로 저장되는지 확인
하자 이미지가 모드와 상관없이 기존 파일명으로 저장되는지 확인
프로그램 재시작 후 모드 ON 상태로 시작하는지 확인
