Clorium 4.7.1.5 미감개선 업데이트 / 2026-10-23

직전 미감개선 4.7.1.4의 기능을 그대로 유지하고 버전을 4.7.1.5로 변경했습니다.
시작 화면·About 제품 표시, Main/Core 파일·제품 버전, Windows 업데이트 EXE 및 매니페스트를 변경했습니다.
내부 어셈블리 참조 버전 2.1.6.0은 기존 모듈 호환을 위해 유지합니다.
AutoSizing은 직전 미감개선 호환 수정본 그대로 함께 포함합니다.

적용: Clorium·AutoSizing 종료 → 업데이트 EXE 더블클릭 → 관리자 권한 허용 → 업데이트.
적용 후 설정 > Custom > 미감개선에서 사용 옵션을 켜고 저장합니다.
촬영 원본: _PR_F / _PR_B, 하자 _D 유지. 치수사진·결과사진·CSV에는 _PR이 붙지 않습니다.
상품 전환 시 상태 유지, 재실행 시 ON. 몬스타덱은 제외입니다.

새 4.7.1.5 후보에서 실행한 검사
- 실제 미감개선·JPEG·치수·WPF: 98개 통과
- 실제 기존 바이너리·WPF·턴테이블: 51개 통과
- 라이선스 인식: 27개 통과
- 컴파일된 버전·촬영 분기·소스 연결: 31개 통과
- Windows 업데이트/재적용/백업/복원: 49개 통과
  원본 설치와 세 가지 기존 4.7.1.4 수정본 및 직전 미감개선 4.7.1.4 → 4.7.1.5 포함.
- 전체 10프로젝트 빌드 및 COM/WIA/WPF 호환 후처리 성공.
직전 촬영 시나리오 375개 결과는 업무 메서드 본문 불변을 확인해 재사용했습니다.

같은 EXE의 [이전 파일 복원]으로 UpdateBackups 아래의 이번 백업을 선택해 되돌릴 수 있습니다.
기존 설치 폴더 및 고객 데이터에는 직접 적용하지 않았습니다.
고객 PC·실제 카메라·턴테이블·USB·운영 API의 최종 현장 확인은 별도입니다.
