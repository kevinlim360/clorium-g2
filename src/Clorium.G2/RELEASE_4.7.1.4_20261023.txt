Clorium 4.7.1.4 업데이트 — 2026-10-23 라이선스 인식 수정

적용 방법
1. Clorium과 AutoSizing을 모두 종료합니다.
2. Clorium_4.7.1.4_20261023_업데이트.exe를 더블클릭합니다.
3. Windows의 관리자 권한 요청을 허용합니다.
4. 기존 설치 폴더를 확인하고 [업데이트]를 누릅니다.
   기본 폴더: C:\Program Files (x86)\Clorium
5. 완료 메시지를 확인하고 기존 Clorium 바로가기로 실행합니다.
6. 라이선스 경고 없이 실행되는지, 시험 상품의 앞면 _F·뒷면 _B·하자 _D 촬영을 확인합니다.

PowerShell·명령 입력·압축 해제·개발 도구 설치는 필요하지 않습니다.
이미 설치된 Clorium용 업데이트이며, 새 PC용 전체 설치 프로그램은 아닙니다.
제품 버전은 4.7.1.4, 수정본 구분은 2026-10-23-license-match입니다.
이전 20261019/20261022 업데이트 대신 이 EXE를 사용하세요.

라이선스 인식 변경
BIOS, 네트워크 MAC, 메인보드, 디스크의 식별자를 모두 확인합니다.
기존 발급 방식으로 계산한 파일명과 D: 루트의 파일이 하나라도 일치하면 인정합니다.
숨김·읽기 전용 파일 및 다른 PC 파일이 함께 있는 경우에도 일치하는 파일을 확인합니다.
실행기 설정 없이 직접 실행하는 경우에도 기존 발급 키와 호환되도록 보완했습니다.
다른 PC의 키 파일, 임의의 .lock 파일, 일치하는 키 파일이 없는 상태는 인정하지 않습니다.
D:의 라이선스 파일, 사진, 고객 설정은 설치 프로그램에서 변경하지 않습니다.
기존 촬영 파일명 오류 및 다음 제품 전환 수정도 포함되어 있습니다.

복원
업데이트 전 파일은 설치 폴더의 UpdateBackups 하위에 자동 백업됩니다.
같은 EXE를 실행하고 [이전 파일 복원]에서 이번 업데이트의 백업 폴더를 선택합니다.
다른 수정본이 추가로 적용되었거나 백업 파일이 손상되었으면 복원을 중단합니다.
이전 파일로 복원하면 이번 라이선스 수정도 되돌아갑니다.

확인 결과
- 기존 코드의 BIOS 우선 검사 및 실행 환경 누락에 따른 거부 현상을 각각 재현했습니다.
- 실제 수정 EXE의 라이선스 검사 27개 통과.
- 전달 EXE에 내장된 Windows 업데이트 엔진/화면 구성 검사 33개 통과.
- 기존 촬영 회귀 163개, 실제 바이너리/WPF/턴테이블 검사 51개 통과.
- 컴파일된 촬영 분기·버전·소스 연결 검사 31개 통과.
- 전체 솔루션 빌드 및 COM/WIA 호환 후처리 성공.

라이선스 검사는 BIOS가 정상이어도 다른 MAC/메인보드/디스크 키를 검사하는 경우,
다중 NIC/디스크 후보, 잘못된 파일과 정상 파일 혼재, 숨김·읽기 전용 파일,
공백이 있는 WMI 식별자, 직접 실행 및 설정 우선값, 다른 PC 파일 거부 등을 포함합니다.
업데이트 검사는 기존 설치/이전 두 4.7.1.4 수정본, 재적용, 해시 검증, 정확한 복원,
원래 PDB가 없는 설치, 잠긴 파일, 손상된 파일·백업, 알 수 없는 수정본 거부 등을 포함합니다.

검증 범위
현재 작업 PC의 실제 설치 폴더는 수정하지 않았고 격리된 사본에서 시험했습니다.
화면 캡처에 나온 고객 PC의 D: 파일과 전체 하드웨어 정보를 직접 읽은 것은 아닙니다.
라이선스 호환 키는 정식 기존 실행기에 포함된 원본 모듈 SHA-256을 확인한 뒤 사용했으며,
실제 값은 소스·보고서·로그에 공개하지 않았습니다. 기존 암호화 방식과 발급 키는 변경하지 않았습니다.
EXE의 관리자 요청 매니페스트와 Windows 폼 구성 및 실제 엔진을 검사했지만 UAC 창을 직접 클릭하는 시험은 하지 않았습니다.
고객 PC에서 최종 실행 확인이 필요하며 실제 카메라/턴테이블 장치 시험은 별도입니다.
