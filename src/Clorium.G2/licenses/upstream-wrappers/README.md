# 모듈별 권리 구분

이 폴더에 digiCamControl 루트 MIT를 세 모듈 전체에 일괄 적용하는 선언을 넣지 않았다. 체크섬 일치 원문 소스의 파일별 저작권·라이선스 헤더를 그대로 보존했다.

- Canon managed wrapper: 원저자 esskar의 Canon-Eos-Framework-LICENSE.TXT를 제공한다. Canon SDK/EDSDK의 파일 고지와 native DLL 배포 조건은 이 wrapper의 MIT와 별도로 확인한다. 이 후보에는 native Canon DLL을 넣지 않았다.
- PortableDeviceLib: 원문에 Vincent Lainé의 LGPL 2.1-or-later 고지가 있다. LGPL-2.1.txt를 제공하며 해당 소스/변경 내용과 고지 보존, 라이브러리 교체·재링크 등 실제 인계 방식에 필요한 조건은 독립 권리 보고서와 최종 배포 구성을 함께 확인한다.
- ZoomAndPan: 원문 RelayCommand/RelayCommandGeneric의 GalaSoft MIT 고지와 나머지 파일별 고지를 보존한다. 특정 파일의 MIT를 다른 파일의 권리로 확대하지 않는다.

두 전문 파일은 독립 검토에서 확인한 공식 upstream/GNU 자료의 해시와 대조하여 복사했다. 이 고지 복사와 로컬 복원 빌드는 고객 배포 권리 확인 완료를 의미하지 않는다.
